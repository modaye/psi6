# 01 视觉语言

状态：阶段二设计稿。色值沿用现有 `Tokens`，本文件不冻结新色，也不授权修改控件实现。

旗舰组合只有四套：浅色现代、深色现代、浅色紧凑、深色紧凑。`Theme.base` 管配色，`Theme.style` 管尺寸，`App.density` 只在运行时决定要不要把另一套尺寸压上去。三者不要写成一个轴。

参考稿在 [`reference/`](reference/)。改前窗口在 [`../../plans/audit-0.7.0/before/`](../../plans/audit-0.7.0/before/)。

## 气质

psi6 画出的是长时间操作的桌面工具：文件、任务、设置、日志、对照。窗口应当像 Windows 11 的设置、VS Code 的侧栏和 JetBrains 的工具窗那样，信息靠对齐、分隔和状态色读出来。

材料是平的。窗口、面板、输入槽、浮层靠已有的四层填充和 1px 分隔线分开。浅色画布保持纯白，深色保持现在已经能分开的石板层级。这些是阶段一截图里站得住的部分，下一阶段照着保留。

现代感来自：对齐的命令、可读的焦点、稳定的状态色、内容区真正占满自己的区域。圆角、阴影和渐变不承担这件事。

可以对照的对象是信息层级和交互，不是配色拷贝：

| 对象 | 拿来用的部分 |
| --- | --- |
| Windows 11 设置 | 阅读列有最大宽度，分组用标题和分隔线，底部动作贴在页面下缘 |
| VS Code / JetBrains | 侧栏、编辑区、工具窗是同一套表面；选中项有明确标记 |
| Figma 桌面端 | 工具栏主动作成组，放不下的命令进溢出，而不是把字截成省略号 |
| PowerToys / 资源管理器 | 数据页是工具栏、筛选、表格，统计是一行状态，不是卡片墙 |
| Linear | 只借密度和键盘焦点可见，不借网页式大圆角卡片 |

## 原则

1. 一个页面先有区域，再往区域里放控件。区域要声明自己的最小尺寸、溢出方式和空状态。
2. 配色和尺寸分开。换浅色深色不改变布局；换现代紧凑不改变区域划分。
3. 交互状态分通道。悬停改填充，焦点画外环，错误改边框并配文字，禁用不走主色。
4. 同一语义只有一种样子。错误、空、忙、选中在输入框、表格、对话框里用同一套角色。
5. 尺寸用逻辑像素。物理像素交给 Qt 的设备像素比，业务代码不乘 `devicePixelRatio`。
6. 已有 token 够用就映射，不为了名单完整新增字段。

## 现代与紧凑

两者只差尺寸。结构、对齐、状态通道、色板角色相同。

数字是 `tokens.py` 里 `_MODERN_METRICS` 与 `_COMPACT_METRICS` 的现值，不是新刻度。

| 角色 | 现代 | 紧凑 | 字段 |
| --- | --- | --- | --- |
| 控件高 | 36 | 30 | `control_height` |
| 小控件高 | 28 | 24 | `control_height_sm` |
| 表行高 | 32 | 28 | `row_height` |
| 图标 | 16 | 14 | `icon_size` |
| 圆角 | 6 | 4 | `radius` / `button_radius` |
| 间距 | 8 / 12 / 16 | 4 / 8 / 10 | `space_sm` / `space_md` / `space_lg` |
| 正文字号 | 13 | 12 | `font_size` |
| 辅助字号 | 12 | 11 | `font_size_sm` |
| 标题字号 | 18 | 16 | `font_size_title` |
| 侧栏宽 | 212 | 188 | `sidebar_width` |
| 图标轨宽 | 56 | 52 | `sidebar_compact_width` |
| 焦点环宽 | 2 | 2 | `focus_ring_width` |

紧凑不是把现代页面缩小后裁字。字重、行的结构、按钮里的文字都保留，只是行高和间距变小。紧凑页仍然要能读完「浏览」「导出日志」这种标签。

`App.density = "auto"` 的现有规则保持：窗口逻辑宽度小于 760 或高度小于 540 时，把紧凑尺寸压到当前主题上；空间够时不把紧凑主题放宽。设备像素比大于等于 2 时，这两个阈值乘 1.25。这是运行时策略，不是第三种 `style`。

## 浅色与深色

两者只差配色。布局、字号、圆角、焦点几何相同。

浅色窗口底是 `#ffffff`。深色四层是 `#161716` / `#1c1d1c` / `#232423` / `#101110`。侧栏是中性灰 `#f7f7f7` / `#121312`，不铺绿色。蕨绿只出现在主按钮、焦点环、链接和选中浅底上。

深色不是把浅色反相，也不是纯黑叠纯黑。主色在深色里是 `#86d0a4`，字是 `#102016`，对比度 9.33。

`base="auto"` 跟随系统浅色或深色，尺寸仍由 `style` 和 `density` 决定。默认浅色和深色都不使用蓝或紫。黑曜石主题仍用靛紫，那是显式切换后的可选皮肤。

## 字体

家族沿用现有栈，不引入新字体：

- 界面：`Segoe UI Variable Text`，然后 `Segoe UI`，然后 `Microsoft YaHei UI`，然后 `sans-serif`。
- 等宽：`Cascadia Mono`，然后 `Consolas`，然后 `monospace`。路径、日志、代码用等宽。

Qt 用 `setPixelSize`。字号是逻辑像素。

| 档 | 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- | --- |
| 标题 | 页面标题 | `font_size_title` | 600 | 1.25 |
| 节标题 | 分组名 | `font_size` | 600 | 1.30 |
| 正文 | 控件文字、表格、消息 | `font_size` | 400 | 1.40 |
| 标签 | 表单左列、工具栏旁的说明 | `font_size` | 600 | 1.30 |
| 辅助 | 字段下的说明、错误句、表头 | `font_size_sm` | 400 | 1.35 |
| 等宽 | 路径、日志、快捷键 | `font_size` | 400 | 1.40 |

没有 Display 档。页面标题到 18（紧凑 16）为止。节标题用正文字号加字重，不再使用样式表里的 `font_size + 2`。

阅读文本一行不超过 72 个汉字宽度的大约值：13px 正文约 560 逻辑像素。设置列、对话气泡、对话框正文都守这个上限。表格和日志不限行长，靠列宽和换行。

## 图标

用 `psi6.icons` 里已有的 24 视图、1.75 描边。绘制尺寸是 `icon_size`。颜色跟所在控件的文字角色走，不单独染色，语义色图标除外（成功、警告、错误、信息用对应颜色）。

每个导航目的地使用不同的图标。选中项图标用 `color_primary`，未选中用 `color_sidebar_text`。

图标按钮的可点尺寸不小于 `control_height_sm`。图标本身仍是 `icon_size`，差出来的是点击区域。

## 圆角

只使用已有字段，禁止在样式里写 `radius + 4` 或写死的 9 / 7 / 2。

| 档 | 用在 | 取值 |
| --- | --- | --- |
| 控件 | 按钮、输入、菜单项、标签、面板、对话框、页签 | `radius`（按钮可用 `button_radius`，默认与 `radius` 相同） |
| 指示器 | 复选框 | `max(2, radius - 2)`；单选为圆形 |
| 窗口 | 仅自绘标题栏窗口的外轮廓 | `window_radius` |

系统标题栏窗口的客户区是直角。默认窗口不自绘标题栏，因此参考页的客户区不加窗口圆角。

面板和按钮共用控件这一档。分档的目的是停掉魔法数字，而不是给每种容器各做一个圆角。

## 边框

全部 1px，逻辑像素。

| 角色 | 字段 | 用在 |
| --- | --- | --- |
| 结构线 | `color_border_subtle` | 分隔线、工具栏底边、行间线 |
| 区域边 | `color_border` | 面板、对话框、表格外框、分栏 |
| 控件边 | `color_control_border`，空则等于 `color_border` | 次按钮、输入、勾选框、下拉 |
| 焦点环 | `color_focus` | 控件外侧的环，不替换控件自己的边 |
| 错误边 | `color_danger` | 无效控件的 1px 边，替换控件边，不另加第二圈 |

主按钮和危险按钮的边与填充同色，这样和次按钮的盒模型一致，边不显成另一条线。

## 表面

| 角色 | 字段 | 用在 |
| --- | --- | --- |
| 窗口 | `color_bg` | 页面画布 |
| 面板 | `color_surface` | 侧栏以外的栏、表格底、设置行悬停 |
| 浮起 | `color_elevated` | 对话框、菜单、Toast、次按钮填充 |
| 下沉 | `color_sunken` | 输入槽、日志、对话记录区 |
| 侧栏 | `color_sidebar` | 主导航 |
| 选中 | `color_selected` | 导航选中、表格选中、列表选中 |
| 悬停 | `color_hover` | 次按钮、行、菜单项 |
| 按下 | `color_pressed` | 由 `color_hover` 与 `color_text` 推导 |

多栏工作台的左、中、右都是面板表面加区域边。窗口底色只从分栏缝里露出来。不允许只有中间一栏有边、两侧直接写在画布上。

页内表面不加投影。对话框、命令面板、Toast 用 `color_overlay` 遮罩（仅模态）加上浮起填充和 1px 区域边。0.7 不新增阴影字段。

## 焦点环

环是唯一的键盘焦点样式。`App` 默认不画，因为有的控件上环很难看；需要对照键盘焦点时传 `focus_ring=True`。`build_stylesheet` 默认仍生成环，方便单独预览。

几何，四种组合相同：

- 控件的边框盒在默认、悬停、按下、焦点、错误、禁用下外沿尺寸不变。
- 独立控件（按钮、输入、开关、图标按钮）的环画在边框盒之外：2px 间隙留出父级表面的颜色，再画 `focus_ring_width`（2px）的 `color_focus` 实线。1px 的缝在抗锯齿之后会并进按钮填充，父级表面就看不见。圆角等于控件圆角加 4。间隙和环算进控件的固定外边距，聚焦时邻居不位移。
- Qt 样式表没有 `outline`，边框也紧贴填充，做不到「环和填充之间再留一条父级色」。实现把 2px 父级表面缝放在环的外侧（`margin`），环本身是预留边框。这和上面的理想几何差一层：缝在环外，不在环与填充之间。
- 两个独立控件的边框盒之间至少 8 逻辑像素。现代的 `space_sm` 已是 8。紧凑的 `space_sm` 是 4，控件与控件之间改用 `space_md`（8）。紧凑的 `space_sm` 仍用于图标和文字之间、控件内部。
- 连成一片的行（侧栏项、表格行、页签条）不把环画到相邻行上。环向行内收 2px，画在该行自己的填充上，行的外沿尺寸不变。行与行之间可以小于 8px。

主按钮上的环必须落在父级表面上。`color_focus` 画在 `color_primary` 上，浅色对比只有 1.52，深色 1.53，所以环贴在主色填充上几乎看不见。同一套 `color_focus` 画在 `color_bg` 上，浅色 8.06，深色 15.17，高于非文字 3.0。所以改位置，不把焦点色换成另一种色相。

错误控件聚焦时保留红色控件边，字段下仍是错误句子。样式表只有一条边，不能同时再在外面加一圈 `color_focus`。

禁用控件不画环，也不给悬停反馈。

## 动效

时长只用现有字段：悬停和按下  `motion_fast_ms`（160），对话框和栏位显隐 `motion_ms`（220）。`reduced_motion` 为真时两者都是 0。

布局尺寸和圆角不动画，避免聚焦和展开时页面跳动。页签指示器的横坐标和宽度可以动画，它不推动其它控件。按钮加载圆弧只旋转，不改变按钮外框。没有入场编排。

### 组件动画清单

同一档时长用在不同控件上要有统一归属，不能每个控件各挑一个数字。这张表是
「哪一档用在哪」的唯一清单；新增动画先查表，查不到再回到本节补一行。

| 组件 | 动画 | 时长 | 缓动 |
| --- | --- | --- | --- |
| `Switch` | 滑块位移 + 轨道颜色同步 | `motion_fast_ms` | 减速 |
| `PressScaleFilter` | 按下缩到 0.94，松开还原 | `motion_fast_ms` | 减速 |
| `AppShell` 侧栏 | 图标轨 ↔ 完整栏的宽度 | `motion_ms` | 减速 |
| `ToastCard` | 高度展开、收起销毁 | `motion_ms` / `motion_fast_ms` | 减速 |
| `UnderlineTabs` / `TabView` 指示器 | 横坐标和宽度滑到当前页签 | `motion_ms` | 减速 |
| 按钮加载圆弧 | 转一圈后循环 | `motion_ms` 的四倍 | 线性 |
| 悬停填充 | 次按钮、行、菜单项的填充 | 不做过渡 | — |

最后一行是刻意的：QSS 的 `:hover` 没有过渡能力，用 `QPropertyAnimation` 模拟
会把每次指针经过都变成一次重绘。悬停只改填充，靠 `motion_fast_ms` 之外的东西
（可读的对比差）表达，而不是靠淡入。

`reduced_motion` 下上表所有行都直接到终值。调用方只认 `psi6.ui.motion`，
不自己建 `QPropertyAnimation`——减少动效的旁路、旧动画的去重、运行期保活都在那一层。

## 留白与密度

留白是区域内部的节奏，不是把控件堆在窗口顶部后剩下的空白。

| 位置 | 取值 |
| --- | --- |
| 页面内边距 | `space_lg` |
| 节与节 | `space_lg` |
| 可聚焦控件之间 | 至少 8，见焦点环一节 |
| 标题与正文 | `space_sm` |
| 控件内文字左右 | `space_md` |
| 图标与文字 | `space_sm` |

短内容页面用底栏或记录区把窗口钉住：设置的动作条贴底，任务的日志占满剩余高度，对话的输入条贴底，文件表占满剩余高度。多出来的垂直空间属于那个区域的表面，不属于「还没设计的画布」。

## 明确不做

- 所有容器各写一个圆角，或在 `radius` 上再加魔法偏移。
- 文件索引、设置、任务页使用卡片网格。入口画廊可以用 `ToolTile`，那是启动器，不是工具页。
- 页内表面加阴影，或用渐变当背景。唯一例外是 `Card(elevated=True)` 的一层轻投影，而且文件索引、设置、任务页不用它铺成卡片墙。
- 次按钮只靠降低不透明度，看起来和禁用相同。
- 关掉焦点环来换取画面干净。
- 加大页边距来换取「现代」。页边距停在 `space_lg`。
- 为旗舰四套之外再做皮肤。Mono、Obsidian、Pine、Brass、ModernDark、CompactDark 维持可加载，不重做。
