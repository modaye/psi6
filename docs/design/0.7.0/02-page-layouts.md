# 02 页面布局

状态：阶段二设计稿。布局用现有控件组合完成，本阶段不改这些控件的外观实现。

尺寸是逻辑像素。现代 / 紧凑只替换 [01](01-visual-language.md) 的度量，不改变区域怎么叠。

窗口按逻辑宽度分三档：

| 档 | 窗口宽度 | 侧栏 | 说明 |
| --- | --- | --- | --- |
| 宽 | ≥ 1100 | 完整 `sidebar_width` | 多栏能同时放下 |
| 中 | 760–1099 | 完整侧栏 | 工作台先收起右栏 |
| 窄 | < 760 | 图标轨 `sidebar_compact_width` | 与 `density=auto` 的收紧阈值同一条线 |

参考应用的最小窗口是 640×420，使 760 这条线拖得到。阶段一的组件目录停在约 921 以上，是因为内容的最小尺寸把窗口顶住了。页面的 `minimumSizeHint` 不得把窗口宽度保持在 760 以上。

内容区宽度 = 窗口宽度 − 侧栏。页面内边距是 `space_lg`。窄窗口在 640、图标轨 56、左右内边距 16 时，内容内宽约 552。除表格外，单个控件的最小宽度不超过 480。表格在自己的视口里横向滚动。

垂直溢出：页头、工具栏、底栏固定；中间区域滚动。滚动条属于中间区域，不把整个窗口包括侧栏一起滚。

下面每节的「参考」指向 [`reference/`](reference/) 里的对应画面。

## 1. 应用壳 Application Shell

适用：有主导航的工具窗口。一页内部的分栏用工作区，换页用 `AppShell`。

结构：

1. 系统标题栏（默认不自绘）。
2. `AppShell` 侧栏。
3. 当前页：页头、可选工具栏、内容、可选底栏。

规则：

- 侧栏全高，贴在客户区左侧。
- 页列填满剩余宽度和高度。
- 一次只显示一个目的地。空标题的目的地不进入导航。
- 窗口宽度 < 760 时侧栏变为图标轨，名称放在工具提示里。
- 内容超出中间区域时，只滚中间区域。

最大内容宽度：壳本身不限制，由当前页决定。内边距：侧栏与页之间没有额外缝，页自己有 `space_lg`。区块间距：不适用。最小尺寸：640×420。对齐：侧栏上对齐，页列拉伸。溢出：中间区域垂直滚动。窄窗口：图标轨，页的窄规则见各页。

参考：每张参考稿都包含这层壳。

## 2. 侧栏导航 Sidebar Navigation

适用：6 个以内的一级目的地。更多目的地进命令面板，不把侧栏变成树。

结构：上为应用名或当前工作区名（一行，超出省略，完整名在工具提示）。下为目的地列表。列表底部不放空项。

规则：

- 项高 = `control_height`。左内边距 `space_md`，图标与文字间距 `space_sm`。
- 每项目的地一个图标，图标名来自 `psi6.icons`。
- 选中：填充 `color_selected`，左侧 2px 竖条 `color_primary`，图标 `color_primary`，文字 `color_text`。`AppShell.set_nav_accent(False)` 去掉竖条。
- 未选中：文字和图标 `color_sidebar_text`。悬停填充 `color_hover`。
- 图标轨只画图标，水平居中。选中竖条保留。

最大宽度：`sidebar_width`。内边距：上下 `space_sm`。间距：项与项 2px。导航项是连排行，焦点环向项内收 2px，不把列表撑开。最小宽度：图标轨。对齐：文字左对齐。溢出：目的地过多时侧栏内部滚动，应用名固定。窄窗口：见上。

参考：`reference/settings/light-modern/wide.png` 与 `reference/settings/light-modern/narrow.png`。

## 3. 页头 Page Header

适用：每一页的内容列顶部。用现有 `PageHeader`。

结构：标题、可选一行说明、右侧最多两个页级动作（例如「打开工作区」）。页头不放开始 / 取消，那是工具栏或底栏的事。

规则：

- 标题用标题档。说明用辅助档、`color_muted`，最多两行。
- 页头不随中间内容滚动。
- 右侧动作是次按钮。放不下时收到溢出菜单，文字不省略成「打开...」。

最大宽度：跟随内容列。内边距：含在页面 `space_lg` 里，页头自身不再加一圈。间距：标题与说明 `space_sm`，页头与下方工具栏 `space_md`。最小高度：标题行。对齐：标题左，动作右。溢出：说明换行。窄窗口：动作先于标题缩小点击区，标题保留一行省略，完整标题在工具提示。

参考：`reference/file-index/light-modern/wide.png`。

## 4. 工具栏 Tool Bar

适用：对当前内容施令的一排命令。用现有 `ToolBar`：主动作在左，次动作在右。

结构：左组（主按钮 + 与它成对的次按钮），弹性空白，右组（筛选以外的次要命令）。筛选不放在工具栏里，单独成行，避免压在分栏线上。

规则：

- 行高 = `control_height`。按钮间距至少 8。
- 「开始」和「取消」同在左组，相邻。
- 窄于 760 时左组保留，右组收进一个 `more` 图标按钮。
- 按钮文字完整显示。组放不下时整颗按钮进入溢出，不在按钮内部省略。

最大宽度：内容列。内边距：0，由页面内边距留白。间距：8。最小高度：`control_height`。对齐：左组左对齐，右组右对齐。溢出：溢出菜单。窄窗口：只留左组加 `more`。

参考：`reference/file-index/light-modern/wide.png`、`reference/file-index/light-modern/narrow.png`。

## 5. 内容容器 Content Container

适用：页头和底栏之间的主体。

结构：一个滚动视口。视口里可以是阅读列、表格、分栏或记录区。

规则：

- 背景是 `color_bg`，除非该页声明主体是下沉表面（对话记录、日志）。
- 短内容不垂直居中，从上往下排。剩余空间留在滚动视口底部，底栏仍然贴在页面下缘。
- 空状态放在声明它的那一块里面，不放在视口之外。

最大宽度：默认撑满内容列。阅读列页面另有 720 的上限，左对齐。内边距：页面 `space_lg`，滚动条出现时不把内容压到侧栏上。间距：由内部区块决定。最小高度：0，把空间让给表格和日志。对齐：上左。溢出：垂直滚动。窄窗口：内部区块按各页改为单列。

## 6. 表单 Form Layout

适用：`FormView`、任务参数、对话框里的字段。

结构：从上到下的字段。每个字段是标签、控件、可选辅助句、可选错误句。

规则：

- 内容宽 ≥ 560 时，标签列宽 200（紧凑 168），控件列在右侧。
- 内容宽 < 560 时，标签在上，控件在下，控件宽度 100% 但不超过字段上限。
- 短字段（文本、数字、下拉）最大宽度 320。路径字段最大宽度 480，右侧跟浏览按钮。开关行的控件是开关，不拉成输入框。
- 错误句在控件正下方，辅助档，`color_danger`。控件边同时为 `color_danger`。
- 字段之间 `space_md`。组标题用节标题，组与组 `space_lg`。

最大宽度：720，左对齐。内边距：0（页面已经有）。间距：见上。最小宽度：280。对齐：标签与控件首行垂直居中；多行辅助时顶对齐。溢出：辅助句和错误句换行。窄窗口：上下堆叠。

参考：`reference/settings/light-modern/wide.png`、`reference/task/light-modern/wide.png`、`reference/settings/light-modern/narrow.png`。

设置页使用这一节，并且默认不把输入框拉到整窗宽度。

## 7. 数据管理 Data Management

适用：文件索引和同类「找到一批记录并处理」的页面。用页头、工具栏、筛选行、`DataTable`。

结构：

1. 页头。
2. 工具栏，主动作成组。
3. 筛选行：搜索、条件下拉、开关。右端一行计数，用辅助色文字加语义标签，不用 `StatCard` 墙。
4. 表格占满剩余高度。空状态画在表格视口内部。

规则：

- 筛选控件保持自然宽度，搜索框最大 280。整行在表格上方，不压在左右分栏的分割线上。
- 表头固定，行高 `row_height`。状态列用 `Tag` 或 `StatusBadge`，不用灰色正文表示成功或失败。
- 宽：名称、路径、状态都显示，路径列弹性并省略，完整路径在工具提示。
- 中：同宽，路径列更窄。
- 窄：隐藏路径列，名称列弹性。横向细节在行的工具提示里。

最大宽度：内容列，表格全宽。内边距：页面 `space_lg`，表格贴着内容内框。间距：筛选行与表格 `space_sm`。最小高度：表格至少 4 行，空间不够时表格内部滚动。对齐：文字左，数量右，标签左。溢出：表格内部滚动。窄窗口：收起路径列，工具栏走溢出。

参考：`reference/file-index/`。空、忙、错误见 `reference/states/file-index-*.png`。

## 8. 任务工作区 Task Workspace

适用：有参数、会跑一段时间、要看日志的任务。阶段一的任务页只有居中的开始和取消，本布局替换那种排法。

结构：

1. 页头，标题是任务名。
2. 中间：参数表单（最大 480）与日志面板并排。日志用 `LogPanel` 或 `LogConsole`，表面下沉，占满剩余宽度和高度。
3. 底栏：左组是开始（主按钮）和取消（次按钮），右端是进度文字或 `StatusProgress`。

规则：

- 窗口内容宽 ≥ 720 时表单在左、日志在右。否则表单在上（高度随字段，不超过中间区域的 45%），日志在下。
- 未运行时日志区内部是空状态「还没有运行」，表单保持可编辑。
- 运行中表单只读，开始不可用，取消可用，进度在底栏。
- 取消只发取消请求，底栏不消失。

最大宽度：表单 480，日志不限。内边距：页面 `space_lg`，两块之间 8。间距：字段用表单节。最小宽度：日志 240。对齐：上对齐。溢出：日志内部滚动，表单过长时左列自己滚动。窄窗口：上下叠放。

参考：`reference/task/`。

## 9. 多面板工作台 Multi-panel Workbench

适用：一页之内要同时看列表、文档和属性。用现有 `Workspace`。不引入可浮动停靠。

结构：工具栏和面包屑在上。下面最多三栏，每栏都是 `color_surface` 加 1px `color_border`。栏间缝 6px，缝的颜色是 `color_bg`，可见的分割线 1px。

最小宽度：左 200，中 360，右 220。三栏最小和加上缝约 792。内容区窄于这个和时，按顺序收起：先右栏，再把左栏收成文档切换（下拉或图标按钮），中栏保留。

规则：

- 左栏是列表，中栏是页签加文档，右栏是 `PropertyList`。
- 右栏收起后，工具栏提供「属性」图标按钮把它临时盖在中栏右侧，宽 260，不把中栏挤到 360 以下。
- 中栏没有文档时，空状态在中栏内部。
- 窄窗口下文字换行或栏内滚动，不从栏的矩形里画出去。

最大宽度：不限，多出来的宽度给中栏。内边距：栏内 `space_md`。间距：栏间 6。最小尺寸：见上。对齐：栏顶对齐。溢出：每栏内部滚动。窄窗口：只留中栏加文档切换。

参考：`reference/workbench/light-modern/wide.png`、`medium.png`、`narrow.png`。

## 10. 设置 Settings

适用：`SettingsPage`。它是表单布局加上固定底栏，不是全宽输入的长页。

结构：

1. 页头「设置」。
2. 滚动的阅读列，最大 720，左对齐。分组用节标题和 `color_border_subtle` 分隔线，组不包进卡片。
3. 底栏贴在内容列下缘，横跨整个内容列（不限于 720）：左侧一行保存状态，右侧取消（次）和保存（主）。

规则：

- 开关行用 `SettingRow`：左说明，右开关。说明可以占满标签列，开关不拉宽。
- 路径行用 `FileInput` / `FolderInput`，浏览按钮在路径框右侧，同组。
- 校验失败时留在字段下，底栏不跳到页面中间。
- 分组之间的空隙是 `space_lg`。短页面的剩余高度落在滚动列底部、底栏之上。

最大宽度：阅读列 720；底栏等于内容列。内边距：`space_lg`。间距：组间 `space_lg`，行间 `space_sm`。最小宽度：280。对齐：阅读列左对齐。溢出：阅读列滚动，页头和底栏固定。窄窗口：字段上下堆叠，底栏的说明收入工具提示，两个按钮保留。

参考：`reference/settings/`。对话框见 `reference/dialogs/`。

## 11. 空状态容器 Empty State

适用：某一块没有记录的时候。用现有 `EmptyState`（图标、标题、一句说明、可选一个动作）。

结构：在宿主区域内部水平垂直居中。宿主有自己的边或表面，空状态不另画一张卡片。

规则：

- 文件表的空状态在表格视口里。日志的空状态在日志里。对话的空状态在记录区里。工作台的空状态在中栏里。
- 页面其他部分保持原样。有数据的表格中间不插入整页空状态。
- 说明告诉下一步动作，例如「选择目录后开始索引」。
- 图标尺寸 `icon_size * 2`，颜色 `color_muted`。

最大宽度：宿主内宽减 `space_lg`，文字最大 360，居中。内边距：`space_lg`。间距：图标与标题 `space_sm`。最小尺寸：宿主至少 `control_height * 4`，否则只显示一行说明。对齐：居中。溢出：说明换行。窄窗口：同一规则。

参考：`reference/states/file-index-empty.png`、`reference/states/task-empty.png`、`reference/states/chat-empty.png`。

## 12. 对话框 Dialog

适用：短时确认和少量字段。用现有 `ContentDialog`。不承担设置页。

结构：遮罩 `color_overlay`，对话框 `color_elevated`，1px `color_border`，圆角 `radius`。无投影。标题、正文或表单、底栏（取消在左，确认在右，危险确认用危险按钮）。

规则：

- 宽 440，最大不超过窗口宽度减 48。字段遵守表单节的 320 上限。
- 打开时焦点在主按钮或第一个无效字段。焦点环可见。
- Esc 关闭对话框，不取消窗口里正在跑的任务。

最大宽度：440。内边距：`space_lg`。间距：标题与正文 `space_sm`，底栏与正文 `space_lg`。最小宽度：320。对齐：屏幕居中。溢出：正文区域滚动，标题和底栏固定。窄窗口：宽度变为窗口减 48，字段堆叠。

参考：`reference/dialogs/confirm-light-modern.png`、`confirm-dark-modern.png`。

## 13. 底栏 Bottom Action Bar

适用：页面级提交。用现有 `ActionBar`。

结构：顶边 1px `color_border_subtle`，背景 `color_bg`。左侧状态文字（辅助色），右侧或左侧的按钮组。任务页的按钮组在左，与工具栏同一侧，避免开始在左上、取消在右上。设置页的按钮组在右，因为保存是页面的结束动作。

规则：

- 高 = `control_height` + 上下各 `space_sm`。
- 主按钮在组内的末位（阅读顺序的确认位）：任务页是「取消、开始」，设置页是「取消、保存」。开始和保存是主按钮。
- 底栏不随内容滚动。
- 窄窗口不把两个按钮拆到两端。状态文字先省略。

最大宽度：内容列全宽。内边距：水平 `space_lg`，垂直 `space_sm`。间距：按钮 8。最小高度：见上。对齐：见上。溢出：状态文字省略，按钮不省略。窄窗口：同一行。

参考：`reference/settings/light-modern/wide.png`、`reference/task/dark-modern/wide.png`。
