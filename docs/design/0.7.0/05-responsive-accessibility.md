# 05 响应式与可访问性

状态：阶段二设计稿。尺寸一律先写逻辑像素。物理像素 = 逻辑像素 × `devicePixelRatio`。样式和布局读取 Qt 的逻辑坐标，不把 token 再乘一遍设备像素比。

## 窗口等级

等级看窗口的逻辑宽度，不看物理分辨率，也不看主题是现代还是紧凑。

| 等级 | 条件 | 布局 |
| --- | --- | --- |
| 宽 | 宽度 ≥ 1100 | 完整侧栏；工作台三栏；表格全部主要列；表单左右列 |
| 中 | 760 ≤ 宽度 < 1100 | 完整侧栏；工作台收起右栏；表格保留路径列但可省略；表单仍左右列（内容宽仍常大于 560） |
| 窄 | 宽度 < 760 | 图标轨；工具栏溢出；表单在内容宽 < 560 时上下堆叠；工作台继续按栏的最小宽度收起 |
| 极小 | 宽度 < 640 或高度 < 420 | 参考应用不再缩小。系统仍可把窗口拉小，此时只保证滚动，不保证三栏 |

高度小于 540 时，`density=auto` 会换上紧凑度量。布局等级仍只看宽度。又矮又宽的窗口保持完整侧栏，中间区域滚动。

高设备像素比：现有规则保持。`devicePixelRatio >= 2` 时，760 和 540 这两个密度阈值乘 1.25。布局等级的 1100 / 760 / 640 不乘这 1.25，否则高分屏上的窄布局会提前发生。密度和布局用两条线，避免混成一个「缩放模式」。

本机阶段一只验证了 100%（设备像素比 1.0，逻辑 DPI 96）和进程内 `QT_SCALE_FACTOR=1.5`。后者是逻辑缩放。系统显示缩放 125% 及以上、macOS、Linux 仍是未决项，见 [08](08-design-decisions.md)。

## 侧栏收缩

窗口宽度一跨过 760 就切换，不等动画结束再改布局。

完整侧栏宽 `sidebar_width`。图标轨宽 `sidebar_compact_width`。轨上的项只保留图标，名称在工具提示中。选中竖条保留。从完整侧栏切到轨时，页的滚动位置保持。

应用名在轨上省略为一枚工作区图标，完整名称在工具提示。

## 工具栏溢出

左组（成对的主命令和取消）始终留在栏上。右组和页头上放不下的次按钮，按从右到左的顺序进入 `more` 图标按钮的菜单。菜单项文字是完整命令名。

判断放不下的方法：按钮的 `sizeHint` 宽度之和大于工具栏内宽，而不是等到文字被省略号截断。按钮内部不使用省略号。

## 表单单列

内容区去掉页面内边距后的宽度 < 560：标签移到控件上方，控件宽度等于这一列，同时不超过短字段 320 或路径字段 480。浏览按钮留在路径框右边；若 480 也放不下，浏览按钮掉到路径框下一行，仍与路径同组。

内容宽 ≥ 560：标签列 200（紧凑度量下 168），控件列在右。

## 多面板折叠

以内容区宽度判断，顺序固定：

1. 放得下左 200 + 中 360 + 右 220 + 两道 6px 缝时，三栏都在。
2. 放不下右栏时，右栏关闭，工具栏出现「属性」。
3. 再放不下左栏时，左栏变成工具栏上的文档切换，只留中栏。
4. 中栏低于 360 时，中栏内部滚动，窗口最小宽度阻止参考应用进入这种状态。

分栏拖动不得把任何可见栏拖过它的最小宽度。拖动结果可以记住，和现有 `Workspace` 的状态文件一样；收起规则在窗口变窄时覆盖记住的宽度。

## 内容滚动

滚动容器是页头与底栏之间的那一层。侧栏目的地过多时，侧栏自己滚，页不跟着滚。表格、树、日志、对话记录在各自视口里滚。

滚动出现时，页头、工具栏、表头、底栏保持可见。焦点移到视口外的控件时，滚动容器把它滚进可见区域，焦点环留在视口内。

禁止用裁切代替滚动。阶段一 `clipped: true` 的数据页和窄工作台，就是缺了这一层。

## 工具提示

必须有工具提示的情况：

- 图标轨上的导航项
- 只有图标的按钮
- 被省略的路径、面包屑祖先、应用名
- 禁用按钮，说明为什么禁用（例如「任务进行中」）

提示用浮起表面和 1px 边，辅助档，无阴影。延迟用平台默认。提示不是错误信息的位置，字段错误仍写在字段下。

## 键盘

Tab 顺序：侧栏项，页头动作，工具栏从左到右，内容区从上到下，底栏按钮。

侧栏、页签、分段、表格、树、菜单里用方向键。表格保留现有的表头排序和选中行行为。

`App` 默认不画焦点环。需要对照键盘焦点时传 `focus_ring=True`。关闭时不画环，也不要留下 Qt 的默认虚线框。打开后环是唯一的键盘焦点样式。

对话框打开后焦点进入对话框，Tab 不走到后面的窗口。关闭后焦点回到打开它的按钮。

命令面板用现有 `ShortcutBook` 登记，一个序列只登记一次。

## 焦点可见性

见 [01](01-visual-language.md) 的几何。验收时要能在浅色和深色上同时指出：

- 主按钮的环落在按钮外面的表面上
- 次按钮的环与它的灰色边是两条线
- 错误输入同时有红色边和焦点环
- 聚焦不改变控件的边框盒尺寸

阶段一的 348 像素浅边不能算通过。

## 对比度

文字 4.5，焦点环和主色竖条这一类非文字 3.0。诊断入口仍是 `contrast_notes`。实现阶段补上「错误色对窗口底」和「焦点色不得作为主按钮的边」这两条说明。

禁用文字允许低于 4.5，因为 `color_disabled` 的现值就是这样，而且它不用于次要说明。

不靠颜色单独表达状态：错误有句子，选中有竖条或行填充加标签，成功失败有标签文字。

## 减少动效

`reduced_motion` 为真时 `motion_fast_ms` 和 `motion_ms` 都是 0。布局切换（侧栏收起、栏折叠）立即完成。进度条可以改变长度，不使用无限循环的装饰动画；忙指示若必须运动，在减少动效时改为静止的「正在运行」文字。

## 高 DPI

参考稿按设备像素比 1 绘制。实现时：

- 字号、控件高、边框 1px、焦点环 2px 都是逻辑像素
- 图标在 24 视图里绘制到 `icon_size` 逻辑像素，由 Qt 栅格化
- 不在 150% 时改用另一套字号

阶段四若要宣称系统缩放通过，必须在 Windows 显示设置里切换缩放后重新截真实窗口，不能只设 `QT_SCALE_FACTOR`。

## 字体回退

界面字体按 `font_family` 的顺序回退。中文落在 `Microsoft YaHei UI`。等宽按 `font_mono` 回退。某一级缺失时使用下一级，不把字号放大来补偿缺字体。

回退后若度量变宽，按钮按 `sizeHint` 变宽，然后才触发工具栏溢出。不先截断文字。
