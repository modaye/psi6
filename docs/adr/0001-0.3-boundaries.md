# 0.3 模块边界

psi6 是给编码 Agent 用的 PySide6 桌面框架：运行时、任务、Python 主题、通用窗壳。控件库留在 `psi6.ui`，不进入框架入口。

## 依赖

允许的方向：`ui` / `templates` → `runtime` 与 `theme`；`runtime.app` 作为组合根，可以接托盘、Toast 和主题应用。`runtime.tasks` 与 `runtime.job` 不得导入 `psi6.ui`。主题定义（`theme.theme`、`theme.tokens`）不得导入 UI 控件。

```
App → TaskRunner、Theme、TrayIcon、窗口几何
TaskRunner → 线程池（不接触控件）
Theme → Tokens
DesktopWindow / BatchToolWindow → App.runner、Theme
```

## 保留、改动、移出

| 概念 | 0.3 决定 | 理由 |
| --- | --- | --- |
| `App`、`run` | 保留。补上主线程约束，禁止嵌套 `run` | 生命周期本来就在这里，缺的是调用契约 |
| `TaskRunner` / `TaskHandle` / `TaskStatus` | 保留。新增 `cancel_requested` | 已是执行器与单次状态，改名没有新语义 |
| `JobOutcome` | 保留为批处理表格数据 | 它不是第二套任务状态 |
| `exclusive` / `is_busy` | 保留 | 同槽互斥是执行器的职责 |
| `BatchToolWindow` | 留在 `psi6.templates`，移出根包 | 可选界面，避免 `import psi6` 带上整套批处理 UI |
| 根包里的控件与 `file_index` | 移出根包，模块路径不变 | Agent 需要分清框架入口和控件库 |
| YAML/TOML/JSON 主题 | 继续不支持 | 0.2 已删除，主题只走 Python 类 |
| 新插件系统、LLM 依赖 | 不做 | 没有调用方 |

## 契约

**App。** 只能在主线程构造和 `run`。已有 `QApplication` 则复用，不另建。`run` 进入一次 `exec`，返回进程退出码；第二实例在 `single_instance=True` 且锁被占用时返回 0，不写窗口几何。默认多开，不记位置。退出顺序：几何（仅 `restore_geometry=True`）→ `runner.shutdown()` → 释放单实例锁 → 隐藏托盘。没有托盘时关闭最后一个窗口仍退出。关窗口本身不取消任务。

**任务。** 状态是 `queued → running → succeeded | failed | cancelled`。`cancel()` 只置请求，状态保持 `running`，直到工作函数返回、抛出 `InterruptedError`，或在请求之后结束。不 `terminate` 线程。`shutdown(timeout_ms)` 对全部任务发取消请求并等待；超时返回 `False`，线程继续跑到函数自己结束。执行器不保存日志历史。`LogPanel` 默认最多保留 2000 条。结果只有 `TaskHandle.result` 上的一个对象。

**主题。** 子类属性必须是 `Tokens` 字段。子类覆盖父类同名字段，未写的字段留在 `base`（`light` 或 `dark`）上。未知字段、错误的 `base`、显式图标目录不存在，都抛错。对比度只通过 `contrast_notes` 报告。图标路径相对主题模块文件。切换主题调用 `App.set_theme`，已显示的控件随 palette 与托盘 `refresh` 更新。
