# 0.3 模块边界

psi6 是给编码 Agent 用的 PySide6 桌面框架：运行时、任务、Python 主题、通用窗壳。控件库留在 `psi6.ui`，不进入框架入口。

## 依赖

允许的方向：`ui` → `runtime` 与 `theme`；`runtime.app` 作为组合根，可以接托盘、Toast 和主题应用。`runtime.tasks` 与 `runtime.job` 不得导入 `psi6.ui`。主题定义（`theme.theme`、`theme.tokens`）不得导入 UI 控件。

```
App → TaskRunner、Theme、TrayIcon、窗口几何
TaskRunner → 线程池（不接触控件）
Theme → Tokens
DesktopWindow → App.runner、Theme
```

## 保留、改动、移出

| 概念 | 0.3 决定 | 理由 |
| --- | --- | --- |
| `App`、`run` | 保留。补上主线程约束，禁止嵌套 `run` | 生命周期本来就在这里，缺的是调用契约 |
| `TaskRunner` / `TaskHandle` / `TaskStatus` | 保留。新增 `cancel_requested` | 已是执行器与单次状态，改名没有新语义 |
| `JobOutcome` | 保留为批处理表格数据 | 它不是第二套任务状态 |
| `exclusive` / `is_busy` | 保留 | 同槽互斥是执行器的职责 |
| `BatchToolWindow` | 0.4 删除 | 整页布局盖住了表单滚动和日志替换，调度仍由 `TaskRunner` 承担 |
| 根包里的控件与 `file_index` | 移出根包，模块路径不变 | Agent 需要分清框架入口和控件库 |
| YAML/TOML/JSON 主题 | 继续不支持 | 0.2 已删除，主题只走 Python 类 |
| 新插件系统、LLM 依赖 | 不做 | 没有调用方 |

## 契约

**App。** 只能在主线程构造和 `run`。已有 `QApplication` 则复用，不另建。`run` 进入一次 `exec`，返回进程退出码；第二实例在 `single_instance=True` 且锁被占用时返回 0，不写窗口几何。默认多开，不记位置。退出顺序：几何（仅 `restore_geometry=True`）→ `runner.shutdown()` → 释放单实例锁 → 隐藏托盘和悬浮球。没有托盘、也没有 `float_ball=True` 时，关闭最后一个窗口仍退出。`float_ball=True` 在屏幕上留一个圆标，关闭主窗口改为隐藏。关窗口本身不取消任务。

**任务。** 状态是 `queued → running → succeeded | failed | cancelled`。`cancel()` 只置请求，状态保持 `running`，直到工作函数返回、抛出 `InterruptedError`，或在请求之后结束。不 `terminate` 线程。`shutdown(timeout_ms)` 对全部任务发取消请求并等待；超时返回 `False`，线程继续跑到函数自己结束。执行器不保存日志历史。`LogPanel` 默认最多保留 2000 条。结果只有 `TaskHandle.result` 上的一个对象。

**主题。** 子类属性必须是 `Tokens` 字段。子类覆盖父类同名字段，未写的字段留在 `base`（`light` 或 `dark`）上。未知字段、错误的 `base`、显式图标目录不存在，都抛错。对比度只通过 `contrast_notes` 报告。图标路径相对主题模块文件。切换主题调用 `App.set_theme`，已显示的控件随 palette 与托盘 `refresh` 更新。

## 0.5 修订

- 删除空的 `psi6.templates` 占位包；整页组合仍由业务代码完成。
- 根包和 `psi6.runtime` 改为 PEP 562 惰性导入：`import psi6` 不再拉起 Qt。`runtime.tasks`、`runtime.job` 可以在没有界面的进程里单独使用。
- Pydantic 字段标记移到 `psi6.schema`，不导入 Qt。`jobs.file_index` 不再依赖 `psi6.ui`，示例自己声明表格列。
- 表单拆为 `ui.form_model`（绑定、校验、错误展示）与 `ui.fields`（控件构造），`ui.form` 只负责排布。`SettingsPage` 复用同一控制器，不再导入私有函数。
- `runtime.notifications` 只依赖 `ToastSink` 协议；`runtime.errors` 提供 `uninstall_exception_hooks`，安装与卸载都由组合根负责。
- 全局 QSS 仍由一个 `build_stylesheet` 生成。拆成多份模板会把 token 和派生色在文件之间来回传，选择器覆盖也仍由测试守住；暂不按控件拆文件。
