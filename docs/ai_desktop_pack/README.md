# AI Desktop Development Infrastructure 评估包

本评估包用于产品经理/技术负责人判断“AI + Python Desktop + UI/Runtime/Skills 基础设施”是否值得立项。

## 文档

1. `01_PRD_AI_Desktop_Development_Infrastructure.docx`：主 PRD，包含背景、定位、MVP、需求、指标、风险、里程碑和评审问题。
2. `02_TAD_AI_Desktop_Architecture.docx`：技术架构设计，重点说明 Runtime、UI Kit、Pydantic Form、Registry、Templates、Renderer 边界。
3. `03_AI_Skills_Context_Registry_Spec.docx`：AI Skills、Context、Registry、CLI/MCP 规范。
4. `04_Feasibility_Evaluation_and_Experiment_Plan.docx`：可行性验证、A/B 实验、Go/No-Go 标准与外部方向验证。

## 建议评审顺序

先看 PRD，再看可行性实验方案，最后看技术架构和 Skills 规范。核心决策不是“技术能不能做”，而是“使用后是否产生可量化的开发效率复利”。
